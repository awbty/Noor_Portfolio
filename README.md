# Noor Portfolio — Presentation

This repository contains a static portfolio website for Noor Al-Huwaidi showcasing selected interior design projects.

The site is structured as a straightforward presentation of work. Each project in the Showroom appears as a curated card that opens a modal containing a gallery and a concise descriptive narrative. The emphasis is on imagery and clear descriptive context rather than interactive complexity.

Structure and approach
- Built with static HTML, CSS and focused JavaScript for gallery and modal behavior.
- Top-level pages are standalone HTML files; the Showroom aggregates project cards and per-project modals.
- Project media is organized under the `images/` directory, grouped by project name.

Content presentation
- Project modals pair a small, curated gallery with written descriptions covering concept, materials, color palette, lighting strategy, and design conclusions.
- Descriptive copy is embedded directly in the modal HTML to keep each project self-contained and immediately viewable.

Image optimization
- Source images were processed with `optimizt` to convert to `webp` and compress assets for efficient web delivery while preserving visual fidelity.

Design intent
- The site intentionally minimizes UI friction so the work is presented like a gallery: clear layouts, simple navigation, and attention on visuals and descriptive context.
